# Security and privacy

This library has no authentication, account store or network service. Never include credentials, real customer records or other personal data in public issues or examples.

For a numerical bug, use a synthetic input and explain the expected result publicly. For a vulnerability that could expose user data on the separate Fate Atlas website, use the support contact shown in the website's privacy page rather than posting sensitive evidence in this repository. No bounty or response-time commitment is implied.
