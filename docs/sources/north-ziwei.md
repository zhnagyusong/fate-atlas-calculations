# 紫微斗数北派河洛与两仪象数算法依据

版本：ziwei-north-heluo-v1，2026-10-21。本站将斗数用法锚定为北派河洛·两仪象数的有限结构实现，不能代称北派全部传承。

## 使用顺序

先核对出生输入、年界和原盘位置，再看生年四化与来因宫；选择宫位后分别查看宫干飞化、离心、向心，并按禄忌或权科分组。星曜不直接映射为人格类型，筛选数量不等于吉凶强弱。

## 安盘和用法分开

安盘保留 iztro 2.6.1 和 ziwei-default-v1 的历法、闰月和早晚子时规则。本次实现的是其上方的四化关系层，未声称通过讲义重新验证了全部安星规则。年干取引擎给出的年界结果，不按公历1月1日猜测。十干四化表与本地固定引擎逐项核对，参考 UP01，并与所读讲义示例交叉核对；不是对所有北派四化异表的裁决。

## NZW-R01 四化表

以年干查表得到生年四化；以宫干查同一版本表得到该宫发出的四化，沿星曜实际位置定位落入宫。禄、权、科、忌属于关系标签，不表示事件判断。表的公开上游参见 UP01。

## NZW-R02 来因宫

依据 N03 PDF第109—110页及 N02 PDF第116页（书内115页），用与生年干相同的宫干定位，并排除子、丑。若不能唯一定位则拒绝输出，不随意选第一个宫位。宫干、宫名和地支分别保留。

## NZW-R03 离心自化

依据 N03 PDF第149页图062，若本宫宫干引动的四化星也在本宫，记为本宫离心自化。记录宫干、星名、四化类别及本宫，不推导离婚、疾病或财务结果。

## NZW-R04 向心自化

同据 N03 PDF第149页，若对宫宫干引动了本宫星曜，记为向心。关系由对宫发出、落入本宫；本宫和对宫以地支相距六位确定。其他宫位飞入本宫仍是飞化，不混称向心。

## NZW-R05 生年与自化分层

N03 PDF第150—151页与 N07 第1讲2的体用段落，支持将生年与自化分层阅读。本项目保留各层记录，不覆盖原生年四化，也不把有自化直接翻译成某种事件。

## NZW-R06 河洛四化数

依据 N01 PDF第8页和 N03 PDF第123页：生年生数为禄4、权2、科3、忌1；自化成数为禄9、权7、科8、忌6。这里是本批资料采用的象数约定，不是邵子天干取数，也不是天文学量值。本版只列数值，不自动进行讲义中的平衡、媒介或用神推演。

## NZW-R07 分象筛选

N09 第3讲1的分象讨论支持按四化类型或组别整理盘面。本版提供全部、禄忌组、权科组和单一四化筛选；所有关系仍保留发出宫和落入宫。筛选只是信息呈现，不能决定哪一个用神必然正确。

## 尚未自动实现

大限流年叠盘、串联并联的语境判定、同干异向与反背的事件解释、用神择取、河洛平衡及应期，均没有被包装成自动报告。讲义中的个案和健康、婚姻、投资等结论不移植为确定性规则。AI与收款状态不因这次资料整理而改变。
