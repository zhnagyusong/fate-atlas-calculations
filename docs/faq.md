# Frequently asked questions / 常见问题

### Is this the whole Fate Atlas website?

No. This repository contains independent calculation modules and synthetic tests. The website's accounts, payments, customer data and private history are excluded. Try the separate [website](https://fateatlas.net).

### Can I run it without an account or an API key?

Yes. Download it, use Node.js22+, and run `npm run example`. No package installation or network request is needed after download. No npm package is currently published.

### 皇极已经能算完整个人命盘吗？

不能。元会运世算术已实现，邵子本命卦是指定规则草案。元堂、后天命卦和正本条文未实现。通用变卦不等于补齐个人命法。

### Is Vedic astrology still only an introduction?

No. Basic geometry is implemented: planets, mean nodes, sidereal ascendant, whole-sign D1, nakshatras, padas and D9 positions. Dasha, predictions and compatibility interpretation are not implemented. The default Lahiri reference model is explicitly approximate.

### Does this prove fortune-telling or verify MBTI?

No. Numerical calculations and culturally selected mappings do not validate predictive accuracy or infer a person's MBTI. The library offers neither matching percentages nor promises about future events.

### Will birth data be uploaded or saved?

The library itself has no network or persistence. Any application that adds storage, analytics, account APIs or external AI must make its own disclosures and obtain appropriate consent.

### Does GitHub publication guarantee search ranking or AI citations?

No. Documentation and reusable examples can make the project easier to discover and understand, but neither indexing, website ranking nor AI citation is guaranteed. Avoid duplicate repositories or keyword stuffing; maintain useful, accurate documentation.
